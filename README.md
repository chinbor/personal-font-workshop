# 个人字体工坊 · Personal Font Workshop

一套面向新手的 Agent Skill：把自己的审美变成可安装、可编辑的英文字体。

不是一键生成器。它引导 AI 助手和你一起确认风格、制作样字、整理矢量轮廓、生成字体，再回到真实使用场景检查。

## 能做什么

- 从少量样字开始，确认风格后再扩展大小写字母、数字和编程常用标点。
- 从原创手绘或授权参考出发，整理单字符 SVG，检查漏字和字符映射。
- 用免费 FontForge 批量生成可编辑 SFD 与可安装 TTF。
- 检查基线、字重、间距、易混字符和小字号可读性。
- 处理字体内部命名、试装说明与授权边界。

默认建议 95 个可打印 ASCII 字符（包含空格），可选加入不换行空格。也支持先做小样和比例间距字体。

## 开始使用

下载仓库后，将包含 `SKILL.md` 的文件夹命名为 `personal-font-workshop`，按 [安装说明](INSTALL.md) 放入工具的技能目录。

在 Codex 中输入：

```text
使用 $personal-font-workshop 帮我做一款自己的英文编程字体。
我是新手，喜欢轻盈圆润的风格，希望使用免费工具。
先做少量样字让我确认，再制作完整字符集。
```

技能本身不依赖收费生图服务。手绘与矢量设计可使用 Krita、Inkscape 等免费工具；已有 Procreate 的用户也可使用，但 Procreate 本身不是免费软件。

## 工具与范围

字符计划和检查工具使用 Python 3.8+ 标准库；构建字体需要带 Python 支持的 FontForge。运行方法见 [构建说明](references/build.md)。

内置构建器处理单个静态 Regular 字体及简化的黑色闭合 SVG 路径，不自动设计字形、不推断丢失的基线、不生成连字。自动检查通过不等于小字号好看，仍需渲染与真实编辑器实测。
