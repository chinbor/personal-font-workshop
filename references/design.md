# 设计与素材

## 开场：把主观审美变成可以调整的选择

用已有上下文填一份短简报；不把问卷一次堆给新手：

| 项目 | 需要确定的结果 |
|---|---|
| 用途 | 编程、正文、手写日记或标题；在哪个软件、什么常用字号 |
| 气质 | 圆润/硬朗，轻盈/厚重，克制/活泼；选少量关键词 |
| 结构 | 等宽/比例，单层/双层 a 和 g，数字 0 的区分方式 |
| 范围 | 本轮样字或完整 ASCII；数字、标点、空格不能默认遗漏 |
| 素材 | 用户手写、自己的矢量、AI 参考或许可允许修改的字体 |
| 限制 | 工具预算、系统、是否愿意手绘、是否需要安装指导 |

先给 2–3 个确实不同的小样方向，用户选定后扩展。已有确认的设计不必重新走选择。寓意可以影响圆角、开放字腔、收笔或重心，但可读性优先；装饰仅在用户喜欢时保留。

## 两条平等路线

**手绘路线**：使用用户已有的绘画工具。iPad/Pencil/Procreate 是可选组合，不是前提。免费替代可考虑 Krita（绘画）、Inkscape（矢量）、FontForge（字体编辑），先检查本机可用性。保留分层母稿与无背景导出。

**AI 辅助路线**：用可用且费用已明确的图像工具探索视觉方向；生成图上的字母逐一核对。模型常出现重复字、缺字、大小写混杂、数字变形。候选图是参考，不是可安装字体，也不自动证明授权清晰。没有图像工具时可直接制作原创矢量小样。

如果用户已有可合法修改的开源字体，以其许可为准，检查 Reserved Font Name、署名、修改版分发要求，不宣称从零原创。商业字体不能凭“只是临摹一点”推定可以复制或发布。

## 建立字形系统

- 先确定基线、cap height、x-height、升部、降部和圆形 overshoot，记录为设计单位；不要把某次项目的 620 字宽或 1000 em 当审美定律。
- 看“视觉粗细”，不是只比较同一条数字宽度。曲线、斜笔、交叉处可能需要光学校正。
- `H O n o` 测直线和曲线，`a e s g` 测字腔，`m w M W` 测拥挤，`i l 1 I |` 和 `0 O o` 测识别，`, . : ; ' "` 测大小和位置。
- 源轮廓使用闭合填充路径，描边先扩展，文字转路径；清掉背景、位图、滤镜、裁剪蒙版和多余节点。孔洞保持正确填充/轮廓方向。
- 自动描摹得到的路径也需要检查自交、尖刺、碎片、假圆角和轮廓点过多。自动布尔/简化可能改变形状，处理前后对比。

## 一份可直接改写的参考图请求

“设计一组原创英文字母小样 H O n o a g，以及数字 0 1 和逗号。风格轻盈、圆润、字腔开放，用于小字号阅读。黑色字形、白底、无阴影、无立体效果；每个字符只出现一次，排清楚。不要模仿指定商业字体。该图仅作风格参考，后续单独制作矢量轮廓。”

将具体风格替换成用户偏好，不能把轻盈圆润固定为所有人的结果。
