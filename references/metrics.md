# 行高诊断与旧字体修复

## 先区分三个对象

构建脚本、交付 TTF、系统已安装文件是三个不同对象。更新构建脚本不会自动修复后两者。先确认用户正在用哪个应用、哪个内部家族名、哪份文件；不要把另一个编辑器的配置当成当前应用配置。

截图只能提示现象。先排查设置覆盖、旧缓存、合成粗体和回退字体，再检查字体；没有证据就保留不确定性。仅询问原因不等于授权改字体、改编辑器或安装。

## 只读检查

本工具需要普通 Python 3.8+ 和免费开源的 fontTools，不需要 FontForge。缺少依赖时说明用途，再按用户授权在其选定环境执行 `python -m pip install fonttools`。

从技能目录运行：

```sh
python -X utf8 scripts/font_metrics.py inspect /path/to/delivered.ttf --compare /path/to/installed.ttf
```

省略 `--compare` 可只检查单个文件。工具不扫描系统、不修改文件；报告内部名称/版本、SHA-256、em、真实轮廓边界及 hhea、OS/2 typo/Win 行高度量。`same_file_bytes` 仅表示两份文件是否相同，不证明编辑器已加载它。

示例使用 `-X utf8`，避免 Windows 在包含中文路径时按系统代码页输出 JSON；调用程序应按 UTF-8 读取输出，报告文件始终为 UTF-8。

没有可靠安装文件路径时，记录“安装文件未确认”，用独立家族名试验、重启应用及截图缩小范围。不要复制注册表条目或修改 CSS 来假装已经修好字体。

## 判断与参数来源

- `hhea`、OS/2 的 typo 和 Win 度量供不同渲染路径使用；它们可能因设计目的而不同，不能只因总和大于 em 就判错。
- 结合原设计参数和真实轮廓范围判断异常。FontForge 新字体的 `*_ascent_add` / `*_descent_add` 可能默认启用，相对偏移被误当成最终数值会让导出结果偏离计划；用绝对模式并重开文件核对。
- 只有缺少默认模式说明不足以证明任意旧字体同样有此问题；对旧 TTF 应读表、对照设计资料和应用表现。
- 修正行框度量不等于移动轮廓。没有字形本身错位的证据时，先保留字形、advance、hinting。上下界至少容纳现有轮廓；组合符号、复杂文字仍要单独排版实测。
- 具体 ascender/descender/gap 从该字体的 em、设计和目标软件确定。没有设计资料时做明确标注的试验参数，不声称恢复了原始意图。

## 生成仅修度量的候选版

以下是 **em=2048 的示例设计**，不是通用默认值；须先确认适合输入字体：

```sh
python -X utf8 scripts/font_metrics.py repair /path/to/original.ttf /path/to/new-trial --family "My Font Metrics Trial" --postscript MyFontMetricsTrial-Regular --version 1.001 --ascent 1700 --descent 500 --line-gap 40
```

`descent` 输入非负数；工具会写入正确的负向 typo/hhea 值。所有度量都显式传入；该辅助工具有意使用一致的 hhea/typo、相应 Win 上下界，并启用 USE_TYPO_METRICS。需要不同度量策略的字体应另做适配。

范围：仅无数字签名、非变量的直立 Regular（weight 400）TrueType 轮廓字体，且 OS/2 版本至少 4；不直接修复 CFF、字体集合、网页字体或其他字重。输入素材必须允许修改；改名不能解除原许可中的限制或保留名称要求。

输出新的 TTF 与 `repair-report.json`。必须使用新 family 和 PostScript 名称，输出目录不能存在；参数不足以容纳轮廓则拒绝。重开后逐字节比对除 `head/hhea/OS/2/name` 外的表，包括轮廓、映射、宽度及存在的提示表。失败时保留诊断产物，不安装或交付为通过版。

该工具不生成 SFD。若需要编辑工程，可在 FontForge 中打开修正后的 TTF 并另存 SFD，不要拿旧 SFD 冒充同步后的源文件；再导出 TTF 时仍需重验度量与轮廓。

## 最后一公里

用户批准后才安装候选版或改设置。保留旧版和原设置，先改成候选内部家族名，保存工作后重启编辑器。行高设置只作为阅读间距的调节项，不替代字体内部度量修复。

按 [编辑器验收记录](quality.md#编辑器验收记录) 检查光标、当前行背景、选区、下伸字符、上下行、空格和混合回退文字。报告状态分开写：度量/文件保持性通过、渲染检查状态、目标应用实测状态。局部截图正常不等于所有字符或所有系统都已通过。
